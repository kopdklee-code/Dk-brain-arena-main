# 가위바위보 하나빼기 (`rps-minus-one`)

진행자 1명과 참가자 전원(최대 29명)이 동시에 겨루는 가위바위보 하나빼기입니다. 진행자를 이긴 사람만 살아남고, 최후의 1인이 남을 때까지 진행합니다.
2026-11-24 사용자 지시로 「단 하나의 숫자」(`unique-number`)를 대체했습니다.

## 규칙 (사용자 확정 — 임의 변경 금지)
1. **① 두 손 내기 (기본 20초)**: 살아 있는 참가자는 바위·가위·보 중 **서로 다른 손 두 개**를 냅니다. 진행자도 진행자 화면에서 두 손을 고릅니다.
2. **② 하나 빼기 (기본 15초)**: 진행자의 두 손이 모두에게 공개됩니다. 참가자는 자기 두 손 중 하나를 남깁니다. 진행자도 자기 두 손 중 하나를 남깁니다.
3. **판정**: 진행자가 남긴 손을 **이긴 사람만 생존**합니다. 비기거나 지면 탈락입니다.
4. **미제출**: ① 또는 ② 단계에서 시간 안에 내지 않으면 탈락입니다.
5. **전원 탈락이면 무효**: 한 라운드에서 살아 있는 사람 모두가 탈락하게 되면, 그 라운드의 탈락은 취소되고 모두 다음 라운드에 참가합니다.
6. **최후의 1인**까지 라운드를 반복합니다. 순위는 늦게 탈락할수록 높고, 같은 라운드에 탈락한 사람은 공동 순위입니다.

- 마감 전에는 고른 손을 바꿔 다시 낼 수 있습니다. 서버가 마지막으로 확인한 손만 인정합니다.
- 진행자 손이 정해져야 그 단계가 마감됩니다.
- 모의 실험(무작위 선택, 29명): 1명이 남기까지 보통 4라운드, 길면 7라운드입니다.

## 파일
| 파일 | 역할 |
|---|---|
| `manifest.json` | 2~29명, `platform` 전용, 판매 게임(`isDemo:false`), 목록 공개 |
| `rules.js` | 판정(`outcome`·`judgeRound`·`standings`)과 진행 단계(순수 함수). 참가자 손은 `playerInput` 계약으로 처리 |
| `view.js` | 진행자·참가자·공개 화면. 결과 공개 연출: 진행자 두 손 → 남긴 손 → 손별 인원 → 생존 발표, 약 4초. 손 모양은 자체 SVG(이모지 미사용). 공개 중에는 생존 인원 표시를 발표 전까지 이전 값으로 유지 |
| `game.css` | `.g-rps` 범위. 디자인 컨셉 「아레나 쇼다운」(스포트라이트 다크 무대 + 네온 포인트). 손 색: 바위 주황·가위 보라·보 하늘, 결과: 생존 초록·탈락 산호(글자 병기). 공개 화면은 1920×1080 안에 스크롤 없이 배치(원형 타이머·제출 점·2단 결과·시상대) |
| 테스트 | `tests/games/rps-minus-one/`: `rules.test.mjs`(단위), `emulator.test.mjs`(29명 시나리오), `e2e.mjs`(브라우저) |

## 진행 단계
| 단계 | 의미 | 다음 |
|---|---|---|
| `LOBBY` | 라운드 시작 전 (규칙 설명, 재진행 대기) | 진행자 `start-round` → `PICK_TWO` |
| `PICK_TWO` | ① 두 손 내기 | 마감 시각이 지나고 진행자 두 손이 정해지면 `close-round` → `PICK_ONE` |
| `PICK_ONE` | ② 하나 빼기 (진행자 두 손 공개) | 마감 시각이 지나고 진행자가 남길 손을 정하면 `close-round` → `ROUND_CLOSED` |
| `ROUND_CLOSED` | 판정 확정, 공개 전 (서버 전용) | `reveal` → `ROUND_RESULT`, 또는 `void-round` → `LOBBY`(같은 라운드 다음 시도) |
| `ROUND_RESULT` | 결과 공개 | 생존 2명 이상이면 다음 라운드, 1명이면 `finish-game` |
| `GAME_FINISHED` | 종료 (정상 종료, 또는 `end-game` 비상 중단) | — |

## 행동
| 행동 | 누가 | 값 |
|---|---|---|
| `pick-two` | 참가자 | 두 손 코드 `12`(바위+가위)·`13`(바위+보)·`23`(가위+보). 1=바위, 2=가위, 3=보 |
| `keep-one` | 참가자 | 자기 두 손 중 하나 (1~3) |
| `host-two` / `host-one` | 진행자 | 위와 같음 |
| `start-round`, `pause`/`resume`, `close-round`(`value` 2=①, 1=②), `reveal`, `skip-reveal`, `void-round`, `finish-game`, `end-game` | 진행자 (`close-round`는 참가자 화면도 예비 요청) | — |

## 비공개 정보
| 정보 | 공개 시점 |
|---|---|
| 참가자 손 | 다른 사람에게는 공개하지 않습니다. 서버 전용 입력 문서와 본인 개인 문서에만 있습니다. 결과에는 손별 인원만 나옵니다. |
| 진행자 두 손 | ② 단계부터 공개합니다. |
| 진행자가 남긴 손 | 결과를 공개할 때만 공개합니다. 진행자 본인 문서에는 있습니다. |
| 진행자 화면 | 참가자 손은 보이지 않고, 제출 인원만 보입니다. |
